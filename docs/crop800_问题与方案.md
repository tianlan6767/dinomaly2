# crop800：漏检与 pred_mask 全黑

数据：`ad_fine_crop_800_5cls`，5 个点位，训练 OK 806 张，测试 203 OK + 223 缺陷。模型 `dinomaly2_fine_crop_800_5cls_in800`，输入 798×798（须被 patch 14 整除）。下面的整图检出都用 `model_5000.pth`。

## 问题

1. 整图已经能判出不少缺陷，但 `pred_mask` 全黑，压伤和点压伤最明显。
2. 热力图上缺陷位置是红的，mask 仍然全黑。例如 `x00768_y01536` 的点压伤 `D4VHVD5CT1E..._phasew`：峰值 0.0322，整图分数 0.0205。
3. 训到 35000 步后整图检出变高，过杀同时明显变差。

## 原因

整图分数和 `pred_mask` 不是同一条规则。

整图分数是异常图最热 1% 像素的均值。798×798 大约是最热的 6368 个像素。门槛是 806 张训练 OK 的这个分数的分位数，再乘 `margin`。测试集不参与定门槛。p99.5 原始分位数是 0.02251。

`pred_mask` 先看整图门：分数不超过门槛，整张直接涂黑，不再看像素。所以热力图已经亮、分数却差 0.002 时，mask 仍是黑的。

另外，Windows 上 `cv2.imwrite` 写中文目录会静默失败。早期评测里压伤、点压伤的 mask 路径在 CSV 里有，磁盘上没有。保存已改为 `cv2.imencode` 加 `tofile`。

把整图分数改成峰值不能解决这张图。同样把测试 OK 过杀压在大约 9 张时，峰值门槛要到 0.0344，这张图的峰值 0.0322 过不去。正常图的焊盘边缘也会出这种尖峰，前 1% 均值就是用来压掉它们的。

继续训练没有拉开缺陷和 OK。图像 AUROC 在 20000 步到顶（五点平均 0.974），35000 步回到 0.972。35000 步把全体分数压低，p99.5 过杀从 9/203 升到 29/203。训练在大约 37300/40000 停下。

## 方案

采用 `model_5000.pth`。不改分数定义，只降低整图门槛，并改 NG 的 mask 像素规则。

整图门槛用 **0.0190**。相对 p99.5 分位数 0.02251，相当于 `margin` 0.844。分数高于 0.0190 判 NG，并允许画 mask；否则 mask 全黑。

过了整图门的图，`pred_mask` 用本图异常图除以本图最大值，大于 0.5 的像素为白。不再使用原来的绝对像素门槛和 0.55 相对比例。

拼图从左到右是原图、GT、`heat/max`、`heat/floor`、`pred`。`pred` 上方标 `score`（整图分数）、`thr`（整图门槛）、`max`（本图异常图最大值）。`heat/max` 只看响应位置，峰值总是红色。`heat/floor` 用绝对尺度，用来看响应够不够强。

## 结果

门槛 0.0190，`model_5000.pth`：

| 项 | 数量 |
|---|---|
| 检测 | 212/223 |
| 过杀 | 22/203 |

对照：

| 设置 | 整图门槛 | 检测 | 过杀 |
|---|---|---|---|
| 5000 步，p99.5，margin 1.0 | 0.02251 | 190/223 | 9/203 |
| 5000 步，p95，约 margin 0.90 | 0.02036 | 207/223 | 13/203 |
| 5000 步，margin 0.95 | 0.02138 | 199/223 | 11/203 |
| 5000 步，margin 0.85 | 0.01913 | 211/223 | 21/203 |
| 5000 步，门槛 0.0190 | 0.01900 | 212/223 | 22/203 |
| 35000 步，p99.5 | 0.01416 | 212/223 | 29/203 |
| 35000 步，p95 | 0.01265 | 217/223 | 80/203 |

0.0204 这一档和 p95 几乎一样，再降到 0.90 不会多检出。0.85 才多检出几张。再降到 margin 0.80（门槛约 0.0180）时，过杀升到 49/203，所以停在 0.0190。

上面那张点压伤分数 0.02045，高于 0.0190，`pred` 上有和热力图红点对齐的白块。

## 还没做

五个点位共用一个门槛。`x07663_y00000` 的点压伤和 `x06912_y00000` 的压伤与正常图重叠程度不同，按点位用各自训练 OK 定门槛还有空间。`x06912` 的压伤和 OK 分数叠在一起，单靠降门槛补不全。
